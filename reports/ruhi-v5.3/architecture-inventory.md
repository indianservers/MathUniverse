# Ruhi v5.3 architecture inventory

Inspection date: 2026-10-08. This checkout contains extensive pre-existing uncommitted work; see initial-working-tree.txt. Inventory describes the actual implementation, not a replacement architecture.

| System | Repository files | Integration |
|---|---|---|
| Entry and routing | src/offline-intelligence/OfflineMathAssistant.tsx; src/math-robo/intelligence/liveAssistant.ts; engineRouter.ts; requestClassifier.ts | Shared assistant; per-mode SemanticEngine, shared session specialist router; turns serialized per mode. Context routing precedes native execution when appropriate. |
| Language | src/math-robo/intelligence/semanticParser.ts; commandLanguage.ts; numberParser.ts; migration.ts; src/offline-intelligence/languageEngine.ts | Typed parser plus compatibility parser. Legacy creation fallback still exists. Multiple parsers are deliberately retained, not fully consolidated. |
| Neural classifier | src/math-robo/intelligence/hierarchicalModel.ts; public/models/math-robo-intelligence-v4/model.json and weights.bin | 768 hashed features, four categorical heads; original inference weights. Predictions normally accompany rule execution. High-confidence CREATE paraphrases still undergo validation. |
| Context network | src/math-robo/intelligence/ruhiContextNet.ts; contextAssistant.ts; contextDataset.ts; pageCapabilities.ts; public/models/ruhi-context-v1 | Separate 848-feature intent/meaning classifier with calibrated abstention and reviewed knowledge/page capabilities. It is not the geometric action classifier. |
| Conversation | src/math-robo/intelligence/conversationEngine.ts; targetResolver.ts; sceneContext.ts; semanticEngine.ts | Scene descriptors, selected IDs, references, previous results, pending slots and working memory. Mathematical specialist pending state also lives in engineRouter.ts. |
| IR and validation | src/math-robo/intelligence/commandIR.ts; commandValidator.ts; executionPlanner.ts; src/math-robo/kernel/structuredExpression.ts; src/math-foundation/types.ts | Command plans and typed mathematical AST are distinct representations. Planner works on cloned scene before effects. |
| Kernel/CAS | src/math-robo/kernel/kernel.ts; exact.ts; safeExpression.ts; domains.ts; assumptions.ts; polynomials.ts; symbolic.ts; advancedCas.ts; symbolicProof.ts; numerical.ts; specialists.ts | Shared exact/conditional/numerical operations, bounded CAS and independent checks. Nerdamer adapts bounded symbolic paths. Specialist registry also routes older engines. |
| Geometry truth | src/math-robo/kernel/geometry2d.ts; geometry3d.ts; conics.ts; geometryConstraints.ts; src/math-robo/intelligence/geometryQueries.ts | Certified Ruhi computations coexist with src/workspace/geometry2dKernel.ts, geometry3dKernel.ts, constructionKernels.ts and native construction controllers. Those native systems are not all backed by the Ruhi kernel. |
| Verification | src/math-robo/intelligence/resultVerifier.ts; src/math-robo/kernel/types.ts; domain/solver modules | Planner and native commit checked separately. Committed count, coordinates, dimensions and styles checked; independent incidence/tangency tests for constructions. Kernel verification is operation-specific, not a universal symbolic proof. |
| Registry/dependencies | src/math-robo/intelligence/workspaceDependencies.ts; src/workspace/objectRegistry.ts; dependencyGraph.ts; universalObjectGraph.ts | Semantic metadata has its own topological recomputation; native construction dependencies are separate. Cycle and invalid-parent handling exists. Unified/native and semantic registries are not interchangeable. |
| Native bridges | src/offline-intelligence/workspaceBridge.ts; geometryAdapter.ts; graph3dAdapter.ts; solidAdapter.ts; commands.ts | Registered mode handlers/readers, known-command inventory, scene notifications, native world-coordinate reconciliation. |
| Graph 2D | src/pages/MathLabGraphingCalculator.tsx; src/components/math-lab/FunctionGraphCanvas.tsx | Function rows store roboCommand; polygon edges share a base ID. Graph expressions render rather than replacing truth coordinates. |
| Geometry 2D | src/pages/MathWorkspace.tsx; src/components/workspace/WorkspaceSvg.tsx; src/workspace/geometryConstructionBuilder.ts | Geometry board converts world coordinates with x=320+40X, y=210-40Y. Native constructions and helper points coexist with semantic metadata. |
| Graph 3D | src/pages/MathLab3DGraphing.tsx; src/offline-intelligence/graph3dAdapter.ts | Surface layers and R3F objects; mathematical (x,y,z) displayed as (x,z,y). Surface fitting/clamping is a display transform. |
| Geometry 3D | src/pages/MathWorkspace.tsx; src/offline-intelligence/shapeGeometry3d.ts; DirectedObject3D.tsx | Added objects store nlpCommand plus native transforms. Native manual objects may not all enter Ruhi's semantic scene. |
| History | src/math-robo/intelligence/semanticEngine.ts; src/workspace/workspaceHistory.ts; src/graph-studio/projectStorage.ts; native pages | Semantic scene snapshots and native workspace histories are distinct. Cinematic intermediate frames suppress native history; final semantic effects are verified. |
| Persistence | src/workspace/workspacePersistence.ts; src/utils/graphWorkspaceStorage.ts; native page serialization | Unified schema v2, graph libraries and native geometry snapshots coexist. Semantic command metadata must survive native restoration. |
| Workers | src/math-robo/kernel/client.ts; kernel.worker.ts; specialistClient.ts; specialist.worker.ts; src/math-robo/intelligence/engineRegistry.ts; training.worker.ts | Kernel active limit 2, idle reuse <=32 jobs/60s, 20s timeout; cancellation terminates worker. Specialist and training workers are separate. |
| Developer distribution | src/pages/ModelTraining.tsx; src/math-robo/SemanticTrainingLab.tsx; Ruhi2dAuditPanel.tsx; IntelligenceReviewPanels.tsx | Training, candidate checkpoints, evaluation and audit controls. An enabled distribution is private; its flag is not authentication. |
| Student build | scripts/build-ruhi.mjs; vite.config.ts; src/math-robo/intelligence/buildPolicy.ts | Compile-time page/worker exclusion. v5.3 additionally removes public training fixtures/manifests from student output after successful build. Local inference weights retained. |
| Animation | src/math-robo/animation/*; src/math-robo/character/RoboAnimationScheduler.ts; src/workspace/animationEngine.ts | Cinematic engine already implemented before this request. Kept intact. Character and native animation systems remain separate. See animation-readiness.md. |

Consolidation is integration verification, not deletion of legacy engines. Current release limits include separate histories, multiple persistence schemas, a partial native-to-semantic registry bridge, and worker cancellation represented as unsupported at kernel level.
