# MathIR and scene persistence

src/math-foundation/mathIR.ts extends the existing MathAstNode, MathValue, MathDomain and MathAssumption representation. It does not install another CAS or rendering engine. MathObjectGraph v1 separates semantic IDs and aliases, mathematical definition, state, units, domain, assumptions and dependencies from VisualCommand render details.

Definitions cover scalar/exact rational/decimal, expression/equation/inequality, coordinate/point, vector/line/segment/ray, circle/sphere, polygon/triangle/rectangle, plane, matrix, transformation and constraint. Actual native definitions are derived only for known point/line/vector/circle/sphere/polygon/triangle/rectangle/plane classes. Other native kinds retain an explicit unsupported definition rather than inventing mathematical support.

The existing semantic scene remains the authoritative scene registry. canonicalObjectGraph produces a validated mathematical projection at transaction and persistence boundaries. Dependencies refer to stable IDs, never labels. Topological validation rejects duplicate IDs, missing parents and cycles before construction recursion. Defined states require finite coordinates, consistent dimensions and positive radius; unit scale/domain and exact rational denominators are validated. Undefined dependent constructions retain their descriptor with a reason and hidden native visibility. The representation has categories for inconsistent and underdetermined states; not every legacy solver emits them yet.

SemanticEngine.exportState serializes a ruhi-scene version-1 envelope with canonical graph, compatible native command descriptors, and up to 100 undo/redo snapshots. The budget is 4 MB. importState validates before native effects, rejects future versions, cross-workspace imports, graph/native disagreement, dangling selections, duplicate identities and dependency cycles. It commits history only after native validation and restores previous native objects on failure. History snapshots and styles retain IDs and authored labels.

Legacy plain RoboSceneContext JSON migrates into version 1 with empty history; absent command schema version means legacy v0. Unknown command versions are rejected. This import/export API supplements existing native workspace saves. Existing Save and Restore saved controls and their native storage formats remain available; a native reload does not automatically restore the new semantic undo stack. The versioned envelope has not replaced every workspace's legacy file format. This distinction is an explicit Phase 1 limitation.

Rollback: revert only Phase 1 source hunks/new modules. Do not revert completed workspace-clear/function-creation edits from the other user task. New envelopes are additive; native workspace save keys were not renamed. Published models and student/trainer separation are unchanged.
