4. Evaluate action/entity/reference/multi-intent/clarification heads only if they add measurable value beyond deterministic adapters. Do not treat this context candidate as a replacement primary command model.
5. Review candidate labels and measured confidence coverage before a trainer-authorized promotion. Pin version + dataset hash + feature/head metadata + immutable model hashes; retain the prior artifact bundle for rollback. Promotion requires an authorized external release process, not a browser role flag.
6. Test current and minimum supported CPU hardware, student build offline caching, representative native controls, saved-session boundaries and arbitrary editing during animations.
