# 300 additional manual graph cases — 2026-10-03

150 new 2D scenarios and 150 new 3D scenarios were entered through the running local app at http://127.0.0.1:4303. Browser controls assisted repeated field entry; observations came from live UI validation, markers, parameters, layer summaries and selected screenshots. No automated test suite was added for this round.

## Scope and limits

Chromium in-app browser, 390 × 844 viewport. This is responsive browser testing, not a physical Android/iOS device or native keyboard test. Each expression is distinct within its graph matrix and does not exactly repeat an expression string in the earlier 300-case fixtures. Two duplicated draft scenarios were replaced and their observations retained separately in JSON.

The observations cover expression entry, validation, domain availability, graph/canvas presence, parameters and mathematical markers. Canvas presence alone does not prove numerical accuracy of every mesh. Invalid-input and no-real-domain cases are intentional; their error/empty output is recorded rather than counted as a crash.

## Fixes and rechecks

- Parse scientific notation without accidental Euler-constant arithmetic or spurious sliders. Reject adjacent malformed decimal tokens.
- Preserve real values for negative bases with odd-denominator rational powers.
- Keep sampling budgets available for later valid domain intervals; remove overlapping refinement that produced false extrema.
- Refine actual roots and reject poles, jumps and exponential underflow plateaus. Include domain-endpoint and cusp roots.
- Distinguish vertical poles from domain boundaries and avoid false horizontal asymptotes for slowly growing functions.
- Resolve coefficient-prefixed parameters and intrinsic parametric coordinates correctly; keep n available outside sequence commands.
- Resolve coefficient-prefixed recurrence prev and validate contour levels.
- Refine narrow finite regions in explicit 3D meshes. Reject incomplete implicit equations.

Affected cases were re-entered after fixes. The JSON preserves both original observations and rechecks; table recheck rows show the latest recorded state. Supplemental image-export download capture timed out in the browser backend, so export behavior is not verified here.

## Case records

“UI valid” means accepted input/render state was observed; “UI error/empty” records an intentional validation/domain check and requires interpreting its expression. “Rechecked” means the case was manually entered again after related fixes.
