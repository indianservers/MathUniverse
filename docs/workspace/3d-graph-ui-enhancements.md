# 3D Graph Studio UI Enhancement Audit

1. Unlimited expression layers with independent identity.
2. Compact layer count and visible-layer summary.
3. Scroll-stable expression manager for long projects.
4. Editable layer names.
5. Inline equation editing with Enter-to-finish.
6. Per-layer visibility controls.
7. Show-all and hide-all commands.
8. Per-layer duplicate action.
9. Per-layer delete action with last-layer protection.
10. Selected-layer highlighting.
11. Per-layer gradient swatches in the list.
12. Custom low and high colour pickers.
13. Built-in height, thermal, contour, and monochrome palettes.
14. Per-layer opacity.
15. Per-layer wireframe mode.
16. Per-layer sample-point display.
17. Per-layer sampling animation.
18. Selected-layer analysis, derivatives, slicing, and CSV export.
19. Selected-layer CAS and 3D Geometry transfer.
20. Error isolation so one invalid layer does not blank valid surfaces.
21. Error count and per-layer inline validation.
22. Visible/total surface counts in the status bar.
23. Legacy two-surface project migration.
24. Unlimited-surface project persistence, undo, redo, and export.
25. Responsive layer and colour controls with fixed action dimensions.
