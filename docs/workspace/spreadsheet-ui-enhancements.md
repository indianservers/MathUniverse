# CAS Spreadsheet: 25 Essential UI Enhancements

Implemented in the spreadsheet studio at `/workspace/data/spreadsheet`.

1. Editable name box for direct cell and range navigation.
2. Shift-arrow keyboard range extension.
3. Ctrl/Cmd+A select-all behavior.
4. Full-row selection from row headers.
5. Full-column selection from column headers.
6. Multi-cell clipboard copy with tab/newline structure.
7. Multi-cell cut and Delete/Backspace clearing.
8. Range-wide formatting instead of active-cell-only formatting.
9. Range border formatting.
10. Merge-range state with inspector visibility.
11. Fill-handle action for propagating the active value or formula.
12. Expandable multi-line formula editor.
13. Search-next navigation through matching cells.
14. Find and replace-next dialog.
15. Replace-all workflow with undo history.
16. Data-validation rules for number, text, and allowed lists.
17. Invalid-cell visual feedback and accessible error state.
18. Split-column and text-to-columns actions.
19. Two-key multi-column sorting.
20. Named-range creation and existing-range inspection.
21. Searchable-style function library with formula insertion.
22. Matrix-function formula seed.
23. Automatic/manual calculation-mode toggle and status.
24. Workbook JSON import plus JSON, CSV, TSV, and print/PDF export choices.
25. Mobile-first inspector behavior: closed on initial phone load and reopened as a bottom sheet.

These enhancements preserve the existing formula engine, regression analysis, dependency graph, CAS/Graph handoff, sheet tabs, undo/redo, and local persistence model.
