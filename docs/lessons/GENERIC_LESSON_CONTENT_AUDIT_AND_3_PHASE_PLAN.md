## Generic Content Signals

A lesson is listed when it uses a family-level preset, a generic interaction, family-generic challenges, an unverified second representation, or generated syllabus copy that only inserts the lesson title into a reusable template.

## Required Replacement Shape

For each lesson, write 100-200 words in simple English. Start with a 2-3 sentence introduction. Then explain: basic idea, how it works, why it happens, where we see it in real life, and one common mistake. Include 2-3 daily-life examples. Use accepted math facts for math lessons and accepted physics facts for physics lessons. Do not guess formulas.

## Phase Plan

### Phase 1: Content Briefs

For every listed lesson, write a short subject brief: exact concept, needed facts or formulas, prerequisites, 2-3 real-life examples, and one common student mistake. Mark lessons that need expert review.

### Phase 2: Lesson-Specific Replacement

Replace generic summaries, explanations, interactions, control guides, examples, practice prompts, and challenges with content tied to the exact lesson title. Keep the required 100-200 word teaching shape for explanatory answers.

### Phase 3: Review and Rollout

Run subject review, route smoke checks, accessibility checks, and tests. Search for generic template phrases. Release by lesson family so mistakes are easy to find and fix.
