# Phase 3 CBSE, AP Intermediate and Telangana Intermediate structures

Eighteen independent pathway records exist: NCERT Classes 6–8; CBSE IX, IX Advanced, X, XI Mathematics, XII Mathematics, XI Applied Mathematics and XII Applied Mathematics; AP BIE IA/IB/IIA/IIB; and Telangana BIE IA/IB/IIA/IIB.

CBSE IX has three partially normalized units and six chapters from the official 2026–27 PDF, with page/section and marks evidence. This is not complete-course mapping. Other CBSE source records are document-ingested but structure review is pending. NCERT evidence remains distinct from CBSE.

AP priority concept backlogs reflect the implementation brief but are labelled authoring priorities, not official mappings. Telangana backlogs remain empty until Telangana's own source is ingested. The board-difference view therefore reports comparison pending and never derives Telangana coverage from AP.

The model supports medium, board order, paper, outcomes, concepts, lessons, practice, assessment, projects, marks/question types, review and certification. Official chapter/terminology/assessment differences will populate only after source review.
