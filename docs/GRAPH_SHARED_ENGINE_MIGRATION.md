# Shared lesson graph migration

## Scope and audit

The main 2D graph workspace and its existing components are out of scope and must remain unchanged. New graph workspace components live under src/modules/lessons/graphs and are opt-in per lesson.

Read the complete inventory: 397 entries, including 50 catalog-only mentions. Source scanning found 835 rendering / sampling files; see [source audit](../test-evidence/shared-lesson-graphs/source-audit.json). This is not browser verification.

Existing reusable systems: FunctionGraphCanvas (SVG sampled curves, regions, vectors, tracing and view interactions); graphViewUtils (pure zoom/fit calculations); adaptiveGraph and graphSampler (sampling); Recharts wrappers for data; GraphCard for outer framing; Three.js / React Three Fiber for spatial lessons; dedicated SVG, canvas and HTML charts. Preserve lesson-owned computations, samples, domains, callbacks, animations and state. Do not force statistical, topological or 3D data through Cartesian curves.

First inventory item is lesson 9, a categorical exponential growth bar chart. Its original bar height has an 8% visibility floor; preserve and document this display convention rather than pretending it is an exact linear scale. Lesson 12 has a custom nonlinear vertical mapping and inconsistent axis labels requiring a separate recorded review before migration.

## Validation and sequence

Work on one lesson at a time in inventory order. Record baseline before migration. Initial family coverage must include function, polynomial, inequality, transformation, polar/parametric, geometry/vector and statistics. No family is certified through typechecking alone. A common shell is not by itself evidence that a renderer has been migrated.
