PRIORITIZED FINDINGS
1. HIGH: Statistics distribution modes all use the same normal PDF/CDF implementation. Binomial, Poisson, Exponential, t and Chi-square choices do not switch the mathematical distribution. DedicatedStudioLabs.tsx:145 onward; catalog advertises all six. Separate distribution atlas pages are not affected by this specific dispatcher.
2. HIGH: Statistics ANOVA is a proxy, not sample-based ANOVA: MSB is variance of three editable means divided by 3; MSW is hardcoded to 1; sample counts/degrees of freedom are absent. The challenge claims equal group means imply F near 1, while setting all means equal produces exactly F=0. RemainingStudioLabs.tsx:465-485; studioMockupCatalog.ts:188. Under a null model E(F) near 1 does not mean observed equal means give F=1.
2a. HIGH: Correlation uses screen-space y coordinates in pearson(), reversing the sign relative to the plotted mathematical axes. At the default r slider value 0.8, the ascending scatter/fit displays r=-0.99. Compute Pearson from model coordinates before mapping them to SVG. RemainingStudioLabs.tsx:443-461; statistics-mode-results.json records the 0.8 input and -0.99 output.
3. HIGH: Default shared figure toolbar operates on useStudioFigure({k:1}) instead of the displayed lab state. Finance: initial principal 10000, edited to 50000, Reset leaves 50000, Undo remains disabled, Share fig decodes to {k:1}. Reset/exact/history/share cannot be considered implemented for model state through this toolbar. Phase1LabChrome.tsx:49-65. Bind each lab state and setters, or remove unsupported controls.
3a. MEDIUM: At desktop 1280x720, .alg-header-actions physically intercepts clicks on the Exponents & Logs Equations tab and CAS Differentiate tab. Both buttons are visible and enabled but sit under Reset/Undo controls. Reproduced ordinary clicks, inspected elementsFromPoint, and saved screenshots. Reflow header actions or give mode tabs their own non-overlapping row.
4. MEDIUM: Confidence-level slider uses only z=1.28 below 95%, 1.96 at 95-98%, and 2.58 at 99%. The observed interval width is 4.67 at both 80% and 90%; 90% should use about 1.645. Capture intervals are deterministic sinusoidal centers, not repeated samples. RemainingStudioLabs.tsx:389-417.
5. MEDIUM: Statistics experiments always generate two-dice sums despite Coins/Cards/Spinner/Conditional/Bayes tabs. Hypothesis tabs all reuse manually entered p versus alpha; confidence modes do not implement proportion/two-sample/bootstrap intervals; correlation modes do not implement residuals/prediction panels; ANOVA modes do not implement a design canvas or diagnostics. Data Explorer supplies repeated fixed scores controlled by n, with no import/filter/brush tool. Descriptive Stats uses immutable data and only swaps selected labels. RemainingStudioLabs.tsx:287 onward.
6. MEDIUM: Four advertised advanced states open home with zero enhancement tools: /geometry?tab=advanced, /trigonometry?tab=advanced, /complex-numbers?tab=advanced and /probability-statistics?tab=advanced. Linear Algebra, Discrete and Modelling advanced states expose 25 tools. MockupStudioApp.tsx:19 only recognizes Linear Algebra advanced; check the distinct wrappers for each route.
7. MEDIUM: Complex Numbers lab frame explicitly disables Undo/Redo for every lab; history is not yet implemented. ComplexNumbersStudioLabs.tsx:68-69 and settings copy. This differs from the fallback toolbar issue because these are the actual routed complex lab components.
8. MEDIUM: Shared challenges usually compare to catalog.expected with a fixed 0.03 tolerance, then report that the answer matches the live model. Finance, population, modular arithmetic and multiple statistics pages pass page.challenge without supplying current model state. Treat these as separate theory questions or derive prompts/expected values from current state. studioLabKit.tsx:196-211.
9. MEDIUM: Build/type validation cannot be called clean: 247 project diagnostics include live Algebra, Calculus, Structures, Geometry, Trig and shared 3D code. The studio test failures are kernel presence for Trig Identities, old CLT text, a Linear Algebra home "Open lab" expectation, and the Discrete Graph link title. Some are stale copy assertions rather than demonstrated broken math.
10. LOW: Algebraic Structures Load example shows "Max on 3" rather than "Max on {0,1,2,3}" because the JSX braces evaluate a comma expression. AlgebraicStructuresLabs.tsx:104.
11. REPORTING: studioWorldClassScore.ts contains assigned 90+ scores, and studioEnhancementManifest.ts marks whole prefixes implemented. These are not measured audit results; inaccessible advanced states and disconnected controls contradict treating the flags as runtime verification.
